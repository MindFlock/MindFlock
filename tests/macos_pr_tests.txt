# The macOS slice of CI on a pull request: test (macos-latest) runs ONLY these
# paths on a PR. The full suite still runs on macOS on every push to main,
# nightly, and via workflow_dispatch (see .github/workflows/ci.yml).
#
# One path per line (no spaces); `#` comments, trailing `# ...` notes and
# blank lines are ignored. A path that no longer exists fails the job, so a
# rename can't silently drop it.
#
# KEEP EACH DIRECTORY'S PATHS TOGETHER (CI also sorts the list): pytest 9
# loses a directory's conftest.py for a file passed after a file from another
# directory that itself followed one from the first — `peer/a.py unit/b.py
# peer/c.py` runs c.py without tests/unit/peer/conftest.py's fixtures.
#
# What belongs here — anything whose behaviour can differ on macOS:
#   * a real tmux server (shutil.which("tmux"), its own -L/-S socket), PTYs
#   * sys.platform / platform.system() / Darwin branches, the seatbelt
#     sandbox, unix sockets (macOS caps AF_UNIX paths at 104 bytes and its
#     tmp dir is a /private/var symlink)
#   * process spawning, signals, zombies, file locks
#   * the session engine's git worktree / tmux / state plumbing
#   * launch parity, installers and install hints, self-update
#   * every file that has ever failed on macOS but not on Ubuntu (marked)
# The peer modules tests/unit/peer/conftest.py marks Linux-only (bubblewrap,
# /proc, memfd) skip on macOS, so they are not listed.
#
# Run it locally with:
#   uv run pytest -n 4 $(sed 's/#.*//' tests/macos_pr_tests.txt | sort)
