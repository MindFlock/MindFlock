Finish setting up WSL

Windows Subsystem for Linux is present, but it doesn’t have a working Linux distribution yet — so MindFlock’s engine has nowhere to run.

Open PowerShell and:

run wsl --install  →  restart your computer  →  run wsl once to finish creating your Linux user.

When wsl drops you into a Linux shell, reopen MindFlock.

Already have a distro? Make sure wsl -l -v lists it (state Running or Stopped), then reopen MindFlock.
